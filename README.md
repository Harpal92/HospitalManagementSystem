# 🏥 Hospital Management System

A Java-based console application to manage patients, doctors, and appointments efficiently.

## 🔑 Key OOP Concepts Demonstrated
- **Abstract Class** — `Person` is abstract, cannot be instantiated directly
- **Inheritance** — `Patient` and `Doctor` extend `Person`
- **Interface** — `MedicalStaff` interface implemented by `Doctor`
- **Custom Exceptions** — `PatientNotFoundException`, `DoctorNotFoundException`
- **File Persistence** — CSV files save and restore data between sessions

## 🚀 Features
- Add, view, delete patients and doctors
- Schedule appointments between patients and doctors
- Data persists across sessions via CSV files
- Auto-incremented independent IDs for patients and doctors

## 🛠️ Tech Stack
- Java 17
- File I/O (BufferedReader, FileWriter)
- OOP Design Principles
